# 页面指令

| method | arg | 作用 |
|---|---|---|
| `page.open` | `home` | 打开媒体库首页 |
| `page.open` | `search` | 打开媒体搜索页 |
| `page.open` | `recycle_bin` | 打开回收站页面 |
| `page.open` | `favorites` | 打开收藏夹页面 |
| `page.open` | `playlists` | 打开播放列表页面 |
| `page.open` | `history` | 打开观看历史页面 |
| `page.open` | `cloud` | 打开云端服务器首页；需先用 `settings.set appearance.show_cloud_tab --extra enabled:b:true` 打开云端入口 |
| `page.open` | `settings` | 打开设置首页 |
| `page.open` | `settings.appearance` | 打开外观设置页 |
| `page.open` | `settings.media_library` | 打开媒体库设置页 |
| `page.open` | `settings.folders` | 打开媒体文件夹管理页 |
| `page.open` | `settings.thumbnails` | 打开缩略图设置页 |
| `page.open` | `settings.player` | 打开播放器设置页 |
| `page.open` | `settings.player_controls` | 打开播放器自定义控件页 |
| `page.open` | `settings.gestures` | 打开手势设置页 |
| `page.open` | `settings.decoder` | 打开解码与视频处理设置页 |
| `page.open` | `settings.audio` | 打开音频设置页 |
| `page.open` | `settings.subtitle` | 打开字幕设置页 |
| `page.open` | `settings.general` | 打开通用设置页 |
| `page.open` | `settings.about` | 打开关于设置页 |
| `page.open` | `settings.libraries` | 打开开源库页面 |
| `page.open` | `settings.logs` | 打开日志页面 |
