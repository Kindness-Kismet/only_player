# 初稿复核记录

复核基线为 `miuix 0.9.4`，固定提交 `39c40f99844227b853f0049a0933b1f3ae6c00ba`。新窗口模块只参考主分支提交 `bb7bde3109605b4c98065b53030ba429c39baea9`，不视为当前依赖已有的能力。

复核方式：重新阅读控件的绘制、布局和默认值，核对项目已有封装；分别截图检查 45 组控件的浅色与深色外观；通过浏览器验证鼠标、键盘、表单、浮层和页面组合。

## 已修正的原版差异

| 问题 | 源码依据 | 修正结果 |
| --- | --- | --- |
| 水平和垂直滑块填充末端是直角，填充位置与白色圆钮不同步 | `SliderTrack` 使用圆头笔画，圆心为半径加有效长度乘进度 | 填充末端改为圆形，位置按轨道厚度计算；零值和满值也保持圆钮完整 |
| 范围滑块的两个端点外加了蓝色描边 | `RangeSliderTrack` 在粗轨道上绘制白色圆钮 | 移除多余描边，填充范围包含两端圆头，起点不得越过终点 |
| 禁用开关与滑块混用了按钮的禁用颜色 | `SwitchDefaults`、`SliderDefaults` 分别使用专用颜色 | 区分禁用轨道、圆钮、按钮文本与滑块填充色 |
| 多选勾选图形只是普通折线近似 | `Checkbox` 按路径长度裁剪到 `0.186..0.803` | 计算稳定态的真实端点；勾选和半选标记按同一视口缩放，表格内不再靠偏移量补位置 |
| 单选标记复用了通用勾选图标 | `RadioButton` 使用 `56 × 56` 视口、笔画 `7` 的专用路径 | 改用原版路径与主色，保留整行选择和键盘单选语义 |
| 色板只有几个预置圆点 | `ColorPalette` 默认七行、十二列色相加一列灰阶，高 `180` | 补齐原版网格、各行饱和度与明度、白色选中环，支持方向键选择；通道滑块放在精细调整区 |
| 数值滚轮选中数字使用蓝色 | `NumberPickerDefaults` 选中颜色为 `onSurface`，默认补充半粗字重 | 改为正文色和半粗字重 |
| 普通按钮文字、提示和消息使用了自定义反色值 | `ButtonDefaults`、`TooltipDefaults`、`SnackbarDefaults` 的色板引用 | 次按钮文字使用 `#303030 / #D9D9D9`；反色提示采用对应表面和文字色 |
| 消息里的撤销按钮缺少蓝色背景 | `SnackbarDefaults.actionContainerColor = primary` | 实际消息和静态样例均使用蓝色胶囊操作按钮 |
| 对话框过宽、圆角偏小 | `DialogDefaults` 最大宽 `420`、圆角 `32`、内边距 `24` | 居中对话框改用这组数值，窄窗口按可用宽度收缩 |
| 环形进度尺寸偏大，缺少轨道圆点样式 | `ProgressIndicatorDefaults` 与三个绘制实现 | 环形改为 `30`、笔画 `4` 和圆头圆弧；补上 `20` 大小的轨道圆点；确定线性进度保留最小圆头 |

## 已修正的布局与交互问题

- 切换分类时，滚动动画可能让标题短暂被顶部栏遮住；改为立即回到页面顶部。
- 播放器在 `320` 像素宽度下，被画面的宽高比和最小高度撑出边界；明确画面宽度并允许内容收缩。
- 对话框和抽屉的最后一个控件之后，浏览器会把焦点临时移到页面本身；补上首尾焦点循环。
- 抽屉里的菜单移入当前模态层显示，避免菜单被模态背景挡住或无法点击。
- 打开菜单前的滚动事件可能延后送达，误把新菜单关闭；现在只在内容位置真正变化时关闭菜单，并检查了窄屏右键与级联菜单。
- 没有尾部标记的菜单项曾被误当作尾部说明，导致文字靠右、字号变小；调整选择器，只对真正的尾部标记应用样式。
- 滑块、字幕大小和音量在多个样例间同步后，填充位置也同步更新。
- 切换分类再返回时，页签内容、收藏状态、字段校验提示和筛选说明与已保存的演示状态保持一致。
- 重置操作恢复播放队列、范围端点、数值和选择状态，并停止未完成的演示扫描。
- 新建片单拒绝纯空白名称，并将新名称显示在片单场景中。
- 加载占位补齐可访问角色，避免无效的命名属性。

## 检查范围

- 浏览器执行并检查脚本错误，所有 45 组样例都有交互实现和设计依据入口。
- 窗口尺寸：`1920 × 1080`、`1440 × 1000`、`1024 × 800`、`768 × 900`、`390 × 844`、`320 × 740`。
- 每个尺寸覆盖浅色、深色、舒展、紧凑及控件图鉴、媒体库、播放器、设置、设计说明，共 `120` 个组合；修正后没有检测到页面或卡片横向溢出。
- 浅色与深色分别截图检查全部控件；截图和检测记录保存在本地 `build/desktop-study/`，不加入提交。
- 验证搜索、清除、单选、多选、半选、排序、组合键选择、范围端点、数值边界、色板键盘、对话框表单、抽屉焦点循环、菜单键盘、队列移动和重置。
- 验证三个页面场景、字幕实时变化、主题切换、设置文件下载，以及直接打开本地网页的离线方式。
- 检查基础可访问语义：图鉴、三个场景、设计说明和抽屉没有发现所选基础规则的违规；未据此宣称满足完整可访问性标准。

本轮没有修改 Android 业务文件或构建配置，没有新增测试文件。原生弹簧物理、触觉反馈、系统窗口材质、真实解码、字幕解析和其他色彩空间的精确转换需要在桌面应用阶段另行验证。
