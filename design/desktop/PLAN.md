# 桌面控件方案

这轮先确定 Only Player 桌面版的控件风格和交互方式，通过可离线打开的网页评审。网页里的媒体、扫描和播放状态使用演示数据，实际桌面应用的播放器内核与文件访问放到后续阶段。

## 研究基线

- 项目当前依赖 `miuix 0.9.4`，以对应标签的源码为主要依据，提交为 `39c40f99844227b853f0049a0933b1f3ae6c00ba`。
- `0.9.4` 已支持桌面平台。基础控件、侧边导航、面包屑、提示气泡、滚动条和跨平台弹窗都有现成实现，可以复用。
- 新的 `miuix-window` 原生窗口与标题栏模块出现在上游主分支，研究时提交为 `bb7bde3109605b4c98065b53030ba429c39baea9`。它不存在于 `0.9.4` 标签中，不能把主分支文档当成当前版本已发布的能力。
- `miuix-ui` 中的 `WindowDialog`、`WindowBottomSheet` 等跨平台浮层，与新的 `miuix-window` 桌面窗口装饰模块是两回事。
- 项目实际主题入口是 `core/ui/.../theme/MiuixAppTheme.kt`，使用组件库色板或系统动态取色。旧的 `Color.kt` 不是当前内置主色的依据。
- 图标沿用项目现有的 MingCute 路径，保持手机端与桌面端的识别一致。

阅读和核对范围包括基础控件源码、偏好设置控件源码、颜色与字体定义、中文组件文档、官方截图，以及项目的主题、按钮、对话框、设置分组和列表封装。

## 风格取向

保留平滑圆角、大片干净表面、克制的分隔线、蓝色操作主色、圆形多选标记、勾选式单选标记和弹性反馈。桌面版主要调整控件密度、信息布局和输入方式。

需要特别保留的原版细节：

- 多选框是实心圆形，半选态显示短横线。
- 单选项选中后显示蓝色勾选标记，未选中时预留标记位置。
- 开关轨道为 `49 × 28`，滑块直径为 `20`，选中和未选中之间的位移为 `21`。
- 滑块使用高 `28` 的粗圆角轨道，白色滑块嵌在已填充部分里。
- 轮廓分段控件在灰色底板内移动选中背景，外围留 `5` 的边距。
- 原版 `TextButton` 默认也带底色；网页中的无底色轻操作按钮属于桌面补充样式。
- 阴影主要用于菜单、弹窗等浮层，普通设置卡片保持平整。

网页通过样式变量统一控制浅色、深色和密度。浏览器支持时使用连续曲率圆角；网页圆角和过渡动画是视觉近似，不能替代原生绘制、弹簧物理参数、系统材质或触觉反馈的验收。

## 鼠标与键盘

- 鼠标悬停只改变背景、亮度或局部尺寸，避免内容整体跳动。
- 常规按钮按下时轻微缩小；开关和滑块保持各自的弹性特征。
- 原生输入元素保留键盘能力；所有可交互元素具有可访问名称和稳定标识。
- 页签使用左右方向键、首尾键切换；菜单使用上下方向键和首尾键移动，右方向键打开子菜单，左方向键返回。
- 关闭弹窗或菜单后，焦点回到触发控件。对话框和抽屉阻止焦点移到背景。
- 空格控制播放；方向键控制播放进度；输入框、菜单和弹窗活动时不截获播放快捷键。
- 列表提供明确复选框，控制键辅助多选，换挡键扩展连续选择。
- 支持减少动态效果的系统偏好；原生阶段进一步确认屏幕阅读器、触摸与高分屏表现。

## 页面场景

媒体库使用侧边导航、路径面包屑、顶部搜索与操作区、网格或表格内容和底部迷你播放栏。验证选中态、排序、搜索、右键菜单和空结果。

播放器使用深色画面区域、可收起的播放列表、底部进度与播放工具、倍速选择和字幕入口。网页只演示控件状态及字幕效果，媒体画面由矢量风景组成。

设置页使用两级导航和分组卡片。展示恢复播放、硬件解码、字幕语言、字幕大小与缓存设置，验证控件在长列表和较窄窗口里的排列。

## 后续原生实现顺序

1. 固定颜色、字体、圆角、密度、焦点与动画变量，以网页作为视觉对照。
2. 优先评估 Compose Desktop 与 `0.9.4` 的跨平台组件，复用成熟基础控件。桌面依赖使用跨平台制品，不直接搬运当前 Android 专用依赖。
3. 将桌面专用的树、表格、工具栏、窗口装饰与播放进度变体单独封装，避免把平台分支散到每个业务页面。
4. 接入媒体库、设置、播放器三个页面，确认窗口缩放、键盘路径和批量操作。
5. 单独接入桌面文件扫描、持久化和播放内核。当前 `core/model` 是纯 Kotlin/JVM，可优先评估复用；含 Android、Hilt、Media3 和平台 IO 的模块需要拆分或替换实现。
6. 窗口模块进入可采用的发布版本后再决定使用方式，并验证原生拖拽、系统窗口菜单和最大化布局。

本轮网页不强制锁定最终桌面技术栈，也不修改 Android 的业务代码或构建配置。

## 网页验收

直接打开同目录的 `index.html`，无需安装依赖或联网。也可从仓库根目录运行：

```bash
python -m http.server 8765 --bind 127.0.0.1 --directory design/desktop
```

在浏览器打开 `http://127.0.0.1:8765`。

验收关注：浅色与深色、舒展与紧凑、不同窗口宽度、控件搜索与分类、开关和选择、滑块与数值、对话框和抽屉、菜单键盘路径、媒体库排序与多选、播放状态和字幕预览。按项目规则，不新增测试文件；通过浏览器实际交互检查并保存本地检查记录。
