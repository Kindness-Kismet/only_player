# Python 风格

适用于根 `scripts/` 与技能 `scripts/` 内的支持脚本。

| 标识符 | 写法 | 示例 |
|---|---|---|
| 模块、函数、方法、参数、局部变量、属性 | snake_case | `read_entry`、`entry_count` |
| 类与异常类型 | CapWords，异常按已有职责命名 | `Command`、`CommandFailure` |
| 模块级常量 | UPPER_SNAKE_CASE | `PROJECT_ROOT` |
| 非公开成员 | 单下划线前缀 | `_buffer_size` |

- 布尔值采用可判断真假的短语，项目自有变量优先 `is_`、`has_`、`can_`、`should_`；外部协议字段和标准库参数保留原拼写。
- 实例方法首参为 `self`，类方法首参为 `cls`；双端下划线只用于语言协议，如 `__iter__`。
- 与关键字冲突时用尾部下划线，如 `class_`。普通内部成员不使用会触发名称改写的双前导下划线。
- 函数参数、数据类字段可能用于关键字调用、构造、模式匹配或字典转换，重命名时一起检查。
- 集合用复数，数量用 `_count`，索引用 `_index`；裸数值单位写进名称，如 `timeout_ms`、`size_bytes`。
- 缩进 4 空格，导入明确名称，不使用通配符；标准库、第三方和项目导入按来源分组。
- 普通 `python` 入口在导入项目模块前设置 `sys.dont_write_bytecode = True` 和 `PYTHONDONTWRITEBYTECODE=1`。从脚本自身位置定位工程，不依赖调用者工作目录。
- CLI 帮助和声明加载不做环境准备或连接应用，执行逻辑按职责分模块；参数和业务输出约定由对应入口所属技能维护。
