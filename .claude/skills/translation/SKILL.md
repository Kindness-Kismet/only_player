# 界面翻译

共享字符串位于 `core/ui/src/main/res/`，默认资源为 `values/strings.xml`，简体中文为 `values-zh-rCN/strings.xml`，繁体中文为 `values-zh-rTW/strings.xml`。先查看实际调用控件、状态和已有译文，再决定复用或新增资源。

## 执行流程

1. 核对文案出现的位置与触发条件，区分按钮动作、进行中、已结束、当前状态和失败原因，在同功能资源与调用处查找已有表达。
2. 同含义、用途和参数优先复用已有资源。键名使用稳定英文语义，沿用已有命名空间；英文相同但含义不同的词分别建项。
3. 根据词典和语境维护译文，新增或修改资源时检查现有各语言的对应项、格式参数和数量词形。原有翻译缺项按本次改动范围处理，记录需要系统回退的实际情况。
4. 用户可见文案通过字符串资源获取，不直接展示内部异常或日志。动态内容作为整句参数传入，允许各语言调整词序。
5. 核对资源 XML、重复键、调用引用、占位符类型与数量；按实际影响执行资源构建与 `AGENTS.md` 要求的检查。涉及截断、排版或状态反馈时用 `app-debug` 验证对应页面。

## 完成与维护

跨页面复用的产品术语更新到项目词典，同步核对本次受影响的资源和调用处。`AGENTS.md` 保留技能触发条件与资源目录来源，译法和操作步骤维护在本技能。

`.codex/skills` 为主源；修改前核对镜像与同步基线，修改后执行 `python scripts/build_support/sync_skills.py --sync`，再执行 `--check`。纯技能文档变更只做内容、链接和镜像核对。
