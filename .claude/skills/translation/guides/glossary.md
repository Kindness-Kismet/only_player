# 项目词典

先按具体含义选择译法；现有产品术语以共享资源中的对应键为依据。

## 已有产品术语

| 资源键或语境 | 简体中文 | 英文 |
|---|---|---|
| `tab_home` | 主页 | Home |
| `tab_cloud` | 云端 | Cloud |
| `tab_favorites` | 收藏 | Favorites |
| `tab_settings` | 设置 | Settings |
| `recycle_bin` | 回收站 | Recycle bin |
| `playlists` | 播放列表 | Playlists |
| `top_bar_style` | 顶栏样式 | Top bar style |
| `navigation_bar_style` | 底栏样式 | Navigation bar style |
| `navigation_bar_style_standard` | 标准 | Standard |
| `navigation_bar_style_floating` | 悬浮 | Floating |
| `navigation_bar_style_miuix` | Miuix 原生（悬浮） | Miuix native (floating) |

协议和产品名沿用 `Only Player`、`HyperOS 4`、`Miuix`、`FTP`、`WebDAV`、`SMB`、`Media3` 的正式写法；资源既有显示文本变更时同步核对同义引用。

## 常用动作与状态

| 用途 | 简体中文 | 英文 |
|---|---|---|
| 结束向导的按钮 | 完成 | Finish |
| 任务状态 | 已完成 | Completed |
| 保存设置按钮 | 保存更改 | Save changes |
| 设置保存后的独立提示 | 设置已保存 | Settings saved |
| 删除文件按钮 | 删除文件 | Delete file |
| 删除进行中 | 删除中 | Deleting… |
| 文件删除结果 | 文件已删除 | File deleted |
| 文件行内删除状态 | 已删除 | Deleted |
| 删除失败且原因未知 | 无法删除文件 | Couldn’t delete the file |
| 删除失败且缺少权限 | 没有权限删除此文件 | You don’t have permission to delete this file. |
| 可以再次尝试的操作 | 重试 | Retry |
| 开启动作 / 状态 | 启用 / 已启用 | Enable / Enabled |
| 关闭动作 / 状态 | 禁用 / 已禁用 | Disable / Disabled |

常用表达用于新增或实际修改的文案，既有资源按具体上下文复用，不因引入词典统一改写整个项目。
