# 字符串写法

- 按钮和菜单用动词开头。中文进度标签用“动作 + 中”，如“删除中”“保存中”“同步中”；任务开始、完成、失败由对应真实状态触发。
- 中文结果优先“对象 + 已 + 动作”，同一行已标明对象时可简写“已删除”。英文按钮用动词原形和句首大写，结果可用 `File deleted` 等短语。
- 标签用短语，提示一句说清；优先写用户能做什么。失败或缺少权限时直接说明事实，恢复方法确实可用时才补充。永久删除等会影响用户决定的后果须明确。
- 协议、API、产品名与行业缩写保留正式写法。中文与相邻英文单词、缩写之间留一个半角空格，如“导出 JSON 文件”。
- 中文数量中阿拉伯数字与量词之间留一个空格，如“已选择 2 个文件”。数量占位符按渲染后的文字留空格；代码、版本号和资源键保留原格式。
- 程序错误返回和日志使用英文；用户可见提示按错误类型、错误码或调用上下文选资源，不直接显示内部异常。未知原因时说明具体哪项操作失败。
- 变量随整句进入资源，避免拼接固定词序；保留参数含义、位置和类型，按目标语言处理单复数，检查 1 与 2 等边界值。
- 同一概念和用途采用同一译法，按钮、状态标签和独立提示按各自语境选词，见 [项目词典](glossary.md)。
